# Contributing

Run the README test and example commands on Python 3.12+. Keep schema changes
versioned and test malformed input, abstention and accounting behavior. Open a
focused issue and feature PR; document purpose, implementation, tests, risks and
limits. Do not add dependencies without a concrete requirement and license review.
Use actual identities and timestamps; do not rotate accounts to simulate
collaboration. Obtain real independent review before merge. Follow
docs/governance.md for the proposed shared decision process.
