UNDER THE HOOD

Evidence you can inspect.

The browser reads each scene's actual RGB pixels, groups connected colored regions, and checks their shape, count, position, or height. The expected answer is computed from those observations—not read from a reference label.

The same narrow rules power OpenForge's Python verifier. Unknown shapes, ambiguous geometry, and unsupported answer formats cause abstention.

This is a software conformance lab for six synthetic fixtures. It is not general image understanding, a live vision-language model, or a model-quality benchmark.
