 OPENFORGE DOCUMENT WORKSPACE

Your sources, in focus.

This application stores projects, uploaded PDFs, extracted text, conversations, and notes in a local database. Documents are not uploaded to a cloud service.

When a local model is available, it can draft answers using retrieved source passages. Otherwise, the application returns matching source excerpts and clearly labels them as search results—not generated answers.

PDFs must contain selectable text. Scanned or encrypted PDFs may not be supported. Text extraction can lose formatting; check the original PDF and cited passages.
